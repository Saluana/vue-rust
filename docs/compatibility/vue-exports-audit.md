## Method

- Runtime exports: `Object.keys(await import('vue'))` minus two CJS interop keys (listed below). The same set is confirmed against `require('vue')` and a `NODE_ENV=production` child process.
- Compile-time macros: functions in vue's type declarations whose JSDoc says "compiler macro" (the `vue.d.ts` closure, following `export * from`).
- Each export is classified into exactly one design row. Its status is the row primary status unless an explicit status is recorded.
- compilerInternal: a vue export with status X that the official compiler emits (helper tables of compiler-core and compiler-dom, and compiler-sfc call sites) and that has no recorded exclusion. These names may be imported by generated code only (`isSupported(..., {origin: "compiler"})`).
