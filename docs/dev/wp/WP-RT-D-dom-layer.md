## Implement
1. **`DocHost`** (`host_doc.rs`): `Host` implemented over `Rc<RefCell<vn_dom::Document>>` plus the `EventSink`. Node ids map `vn_dom::NodeId`↔`HostNode` (ask the coordinator via your report if `NodeId` needs `raw()/from_raw()` accessors — add them to `crates/dom/src/node.rs` yourself as a 4-line change if absent; you are authorised for exactly that). Re-entrancy requirement: while `Document::insert_before/remove_child/set_text_content/focus/blur/click/dispatch_event/...` run listeners through the `Invoke` callback, the JS handler may call back into the host (read `el.value`, set attributes, trigger focus…). Because the `Invoke` callback gets `&mut Document`, make the callback **swap the live document into the shared cell for the duration of the sink call and swap it back** (`std::mem::swap` with the cell content; document it), so nested host calls see a consistent document; add a re-entrancy test (listener on `blur` that reads/writes the DOM while `remove` is executing). The sink adapter converts `vn_dom::EventState` ↔ `HostEvent`/`ListenerOutcome`. Also provide the *test-host surface*: `DocHost::dispatch_event(target, EventInit-like)`, `click(node)`, `focus`, fake clock `now_ms` (settable), `snapshot(node)` (vn-dom's canonical JSON), `body()` container creation for apps (`#app` helper) and `query_selector`.
2. **`dom_props.rs`**: `patch_prop(rt, host, el, key, prev: &Value, next: &Value, ns, ctx)` implementing runtime-dom's decision tree exactly (class → `className`/`class` attr + transition classes `_vtc` hook point, style objects/strings with `display` restore (`vShow` interplay), `on*` → events, `.prop`/`^attr` modifiers, `shouldSetAsProp` using `Host::has_property` and the boolean-attribute/`innerHTML`/`textContent` special cases (`innerHTML` is Unsupported on native hosts → a `TypeError` with a clear message), `value` for `input/textarea/select/option/progress`, `checked`, `type` on input/button, `form`, `list`, `width/height` on img…), coercions (`''` for boolean props → true, `null`/`undefined` removal rules, `Number` → string for attributes), per-element expando state kept in a Rust side-table keyed by `HostNode` (invokers `_vei`, `_value`, `_assign`, `_vod`, `_vtc`, composing flag) that is traced by the GC. Provide `patch_props_diff` helper if the renderer WP needs it (RT-C will call `patch_prop` per key).
3. **`dom_events.rs`**: invokers with the `attached`/timestamp guard (clock = `Host::now_ms`), listener registration via `Host::add_event_listener` with option parsing from names (`onClickOnce`, `onKeydownCapture`, `onTouchstartPassive`), arrays of handlers, handler replacement without re-adding listeners, error routing (`callWithAsyncErrorHandling` stand-in: a hook the runtime error WP fills — for now a function pointer that rethrows to the host's sink), the **JS event object** (`Event`-like plain heap object with `type target currentTarget eventPhase bubbles cancelable defaultPrevented timeStamp isTrusted:true key code ctrlKey shiftKey altKey metaKey button clientX clientY detail data isComposing` + methods `preventDefault stopPropagation stopImmediatePropagation composedPath` that set flags returned in `ListenerOutcome`; `target`/`currentTarget` are lightweight **element handle objects** (`ObjectKind::Native` with the `HostNode`, exposing `value checked tagName id className getAttribute…` through an exotic read/write bridge: reading `event.target.value` calls `Host::get_property`; writing sets it) — design these handles so `v-model`'s getter code and typical user handlers (`e.target.value`) work.
4. **`vmodel.rs`, `vshow.rs`, `withModifiers/withKeys`** as directives/functions with exactly runtime-dom's hooks (`created/mounted/beforeUpdate/updated/deep/getSSRProps` fields as a directive object value — the `directives.rs` machinery (RT-C) will call them; keep the directive hook signatures documented), modifiers (`stop prevent self ctrl shift alt meta left middle right exact`, keys `enter tab delete esc space up down left right` + custom hyphenated key names), `vModelText` composition handling, `.lazy/.trim/.number`, `vModelCheckbox` (arrays/Sets/true-value/false-value), `vModelRadio`, `vModelSelect` (single, multiple, `_value` objects, `looseEqual`), `vShow` (display toggle with `_vod`).
