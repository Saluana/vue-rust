## Deliver
1. `vn_uikit::install(rt: &Rt, host: Rc<RefCell<DocHost>>)` / `ui_setup(rt)`: installs `testHost.mount(component, props?, options?)` (creates a fresh container element `#app-N` in the DocHost's body, `create_app(component, props)` with `options.errorHandler`, mounts) returning a `Mount` object (`snapshot() html() unmount() setProps(next)`), `testHost.find/findAll(mount|node, selector)` (selector grammar of the contract), `NodeHandle` (`text html attr prop exists snapshot`), `click input change check select keydown focus dispatch tick container(id)`; all as native functions/objects on the heap (GC-traced; no Rust closure owns a `Value`), event dispatch through `DocHost` (real bubbling/capture, activation behaviour, `input()` sets the `value` property then dispatches `input`, `check()` performs `click`), `tick()` = `await nextTick()` + job drain via the existing `testHost.tick` promise machinery, fake clock shared with `testHost.timers` (`DocHost::now_ms`).
