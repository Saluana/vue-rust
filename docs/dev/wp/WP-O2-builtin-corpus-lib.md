## Do
1. `tooling/oracle/builtin-corpus.mjs`: `defineSuite`, `writeSuite`, callback presets exactly as specified (log entries `[presetName, ...scalarArgs]`),
   path resolution of `target` from `globalThis` (`Array.prototype.slice`, `Object.keys`, `Math.max`, `new:Map`), execution with `try/catch` capturing `e.name`,
   encoding via a fresh `createRecorder()` per pass (pre pass; post pass), deterministic output (stable key order, no timestamps), validation (unknown target → error).
   Provide `decodeCaseForDocs`? No — decoding is the Rust side's job; but export `describeCase(c)` for debugging.
2. Seed suites in `tests/language/builtins/` generated by `tests/language/gen/gen-builtins.mjs` (deterministic; run it twice → identical bytes):
   - `math.json`: every `Math.*` function the manifest lists as supported (abs ceil floor round trunc sign sqrt cbrt pow exp expm1 log log2 log10 log1p sin cos tan asin acos atan atan2
     sinh cosh tanh asinh acosh atanh min max hypot fround clz32 imul + constants) over ~40 argument edge values each (NaN, ±0, ±Infinity, tiny, huge, negatives, fractions, 2^53),
     and arity edge cases (no args, one arg, many, non-number args coerced from strings/booleans/null/undefined). **Note:** `Math.random` is excluded; trigonometric/exp/log results
     are platform libm-dependent — record V8's results anyway and mark cases where V8 and the platform libm may differ in the last ulp with `"approx": 1` (ulp tolerance) so the Rust
     replay can allow ≤ 1 ulp on those functions only.
   - `number.json`: `Number.isInteger/isSafeInteger/isFinite/isNaN/parseFloat/parseInt`, `Number.prototype.toString(radix)/toFixed/toPrecision/toExponential/valueOf` (a sample, not duplicating the L1
     corpora), `Number(...)` coercions of ~60 values.
   - `object-statics.json`: `Object.keys/values/entries/assign/fromEntries/freeze/isFrozen/seal/isSealed/preventExtensions/isExtensible/hasOwn/is/getPrototypeOf/create(null)` over plain objects,
     arrays, strings, nested/aliased objects, integer-like keys ordering, null/undefined arguments (TypeError), frozen objects.
3. `tests/language/builtin-corpus.test.mjs` (node:test): every suite regenerates byte-identically; each case's `pre`/`post` round-trips against a **fresh independent re-execution** in a child process
   (guards against nondeterminism); preset behaviour tests with hand-written expectations; encoding spot checks written by hand; negative control (a case whose expectation is mutated is detected by the
   suite checker `checkSuite(path)` you export: it re-executes in Node and diffs).
4. A short `tests/language/builtins/README.md` listing how later WPs add suites.

## Acceptance
`node --test "tests/language/builtin-corpus.test.mjs"` passes; `node tests/language/gen/gen-builtins.mjs` is deterministic; suites include ≥ 600 cases in total.
